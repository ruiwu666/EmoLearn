## Overview

EmoLearn detects student engagement from webcam video during online learning. It processes 10-second video clips through two visual modalities — **facial appearance** (ResNet-18 embeddings, 512-dim) and **geometric features** (MediaPipe head pose + eye/mouth measurements, 6-dim) — and classifies engagement as Low or High. States like Confusion,Frustration, and Boredom are also studied.

Built for **CS466 Multimodal Interaction and Learning** at Colby College, Spring 2026.

### Key Results

| Metric | Baseline | Best: Stat MLP+OS |
|--------|----------|-------------------|
| Accuracy | 94.8% | 90.4% |
| F1 Macro | 0.487 | **0.628** (+28.5%) |
| Low Recall | 0% | 41% |

The baseline gets 94.8% accuracy by predicting "engaged" for everyone — but detects zero struggling students. Our model actually finds the struggling students.

## Dataset

**DAiSEE** (Dataset for Affective States in E-Environments)

- 9,068 video clips (10 sec each, 30fps) from 112 students at IIIT-Hyderabad
- 4 affective states: Boredom, Engagement, Confusion, Frustration
- 4-level labels (Very Low → Very High), 10 crowdworkers per clip
- Extreme imbalance: 95.2% of engagement labels are High/Very High

Download from [DAiSEE](https://people.iith.ac.in/vineethnb/resources/daisee/index.html) and update `DAISEE_ROOT` in each script.

## Pipeline

```
Video (10s, 300 frames)
    │
    ▼
Sample 10 frames uniformly
    │
    ▼
Face Detection (MediaPipe)
    │
    ├──► Lens 1: Appearance                 Lens 2: Geometric
    │    Face crop → ResNet-18 → 512-dim     478 landmarks → 6 features
    │    (texture, expression, micro-        (pitch, yaw, roll,
    │     expressions)                        L_EAR, R_EAR, MAR)
    │               │                                │
    │               ▼                                ▼
    │         Statistical Features:  mean, std, min, max across frames
    │               │                                │
    │               └────────────┬───────────────────┘
    │                            ▼
    │                    GRU + Attention Fusion
    │                    (or Stat MLP / MIL)
    │                            │
    │                            ▼
    └──────────────►     Engaged / Not Engaged
```

## Models Tested

### Architectures
| Category | Models | Description |
|----------|--------|-------------|
| Baseline | MLP | Averaged or statistical features → FC layers |
| Temporal | LSTM, GRU | Frame sequences (10×D) → recurrent network |
| Fusion | Early, Late, Attention | Different modality combination strategies |
| MIL | Attention MIL, Gated MIL | Bag-of-frames with learned frame importance |
| Statistical | Stat MLP | Mean/std/min/max features → FC layers |

### Imbalance Handling
| Strategy | F1 Effect |
|----------|-----------|
| Cross-Entropy only | 0.487 (predicts all "High") |
| + Oversampling | 0.563 |
| + Focal Loss (γ=2) + OS | 0.598 |
| Statistical Features + OS | **0.628** |

## How to Run

### Requirements
```
Python 3.13+
PyTorch (with MPS for Apple Silicon, or CUDA)
torchvision
mediapipe >= 0.10.30
opencv-python
numpy, pandas, matplotlib, scikit-learn, scipy
```

Install:
```bash
pip install torch torchvision mediapipe opencv-python numpy pandas matplotlib scikit-learn scipy
```

### Step-by-step

```bash
# 1. Feature extraction (run once, ~45 min on M4)
python src/0_pipeline.py

# 2. MLP baselines (Check-In 2)
python src/1_baselines_mlp.py

# 3. Full experiments: LSTM/GRU/Attention + binary + imbalance handling
python src/2_final_optimization.py

# 4. Improvements: stat features, MIL, gender analysis, LOUO
python src/3_mil_and_analysis.py

# 5. All 4 affective states
python src/allStates.py

# 6. Demo on single video
python src/demo.py
```

Or open the notebooks in `notebooks/` to see pre-computed results without running.

## Results

### Binary Engagement Classification

| Model | Accuracy | F1 Macro | Strategy |
|-------|----------|----------|----------|
| **Stat Fusion MLP+OS** | 90.4% | **0.628** | Statistical + CE + OS |
| Attn GRU+Focal+OS | 92.1% | 0.598 | Temporal + Focal + OS |
| Attention MIL+OS | 91.0% | 0.583 | MIL + CE + OS |
| CE Baselines | 94.8% | 0.487 | Predicts all "High" |
| DAiSEE Paper (LRCN) | 94.6% | — | |

### All 4 Affective States (Binary, Stat MLP+OS)

| State | Accuracy | F1 Macro | Minority % |
|-------|----------|----------|------------|
| Engagement | 90.4% | **0.628** | 4.8% |
| Confusion | 84.3% | 0.579 | 9.5% |
| Frustration | 87.0% | 0.563 | 4.6% |
| Boredom | 58.2% | 0.494 | 24.5% |

### Gender Analysis

| Metric | Female (n=337) | Male (n=1,301) |
|--------|---------------|----------------|
| F1 Macro | **0.586** | 0.550 |
| Low Recall | **42%** | 11% |

Higher F1 for females despite lower accuracy — driven by class distribution differences, not gender bias.

### Leave-One-User-Out (20 sampled users)

| | Standard Split | LOUO |
|--|---------------|------|
| F1 Macro | 0.628 | 0.333 ± 0.184 |

Significant generalization gap — the model learns person-specific patterns.

---

## Key Findings

1. **Appearance >> Geometric** — 512-dim facial texture outperforms 6-dim head pose
2. **Statistical features beat temporal models** — mean/std/min/max matches GRU
3. **Data imbalance matters most** — focal loss + oversampling > model architecture
4. **Simpler is better** — GRU > LSTM, Stat MLP > GRU on limited data
5. **Generalization is hard** — LOUO drops F1 from 0.628 to 0.333
